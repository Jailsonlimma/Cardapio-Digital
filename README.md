# Cardápio Digital - Casa Brasa

Fiz esse projeto pra treinar HTML, CSS e JavaScript. É um cardápio online de uma lanchonete (inventada) onde a pessoa escolhe os lanches, coloca no carrinho e manda o pedido pelo WhatsApp.

Os preços, o endereço e o número do WhatsApp são de mentira.

Dá pra ver funcionando aqui: https://jailsonlimma.github.io/Cardapio-Digital/

## O que ele faz

- mostra os produtos separados por categoria
- dá pra adicionar e tirar itens do carrinho
- o carrinho fica salvo mesmo se fechar a página
- no final monta a mensagem do pedido e abre o WhatsApp
- funciona no celular e no computador

## O que eu usei

HTML, CSS e JavaScript puro, sem framework.

## Como mudar os produtos

Os produtos, as categorias e os dados da loja ficam todos no arquivo `menu-data.js`. É só editar lá.

## Como abrir

Pode abrir o `index.html` direto no navegador.

## O que aprendi

Aprendi a montar a página a partir de uma lista de dados no JavaScript, a usar o `localStorage` e a deixar o layout bom no celular. Ainda quero melhorar algumas coisas, tipo colocar uma busca de produtos.
